# 📦 TokenStockMonitor — Coding Plan 补货提醒

> 一个 Chrome 扩展，后台监控 **GLM Coding Plan** 和 **Kimi Code Plan** 的套餐状态，状态一变就通过**企业微信群机器人**推送到你的群。
>
> **仅提醒补货状态变化，不做任何抢购或下单动作。** 你只需要保持 Chrome 开着并登录好账号，其余交给插件。

---

## ✨ 功能特性

- 🤖 **GLM Coding Plan**：放货窗口前自动开页 + 放货那一秒精确刷新，套餐状态变化时提醒
- 🔔 **Kimi Code Plan**：后台定时调接口，候补→开放时提醒，**无需打开任何页面**
- 💬 **企业微信通知**：群机器人 markdown 消息，带可点击直达链接
- 🔐 **登录态健康检查**：放货前 30 分钟预检登录、每 30 分钟静默保活、失效立即告警
- ⏱️ **秒级刷新**：放货时刻精确到秒的 setTimeout 刷新，尽量第一时间发现状态变化
- 📋 **两层日志**：前端只显示关键事件，后台保留完整调试信息，方便复盘
- 🎛️ **全可配置**：放货时间、提前开页分钟、Kimi 检查间隔、监控套餐，全在弹窗里调

> ⚠️ **关于准确性**：本插件只能提醒「套餐状态发生了变化」（如按钮从售罄变为可购买）。目前 GLM 售罄态判断已用真实样本验证，但「可购买」态尚未经历过真实放货检验，无法保证 100% 准确识别。请以实际页面为准。

## 🧠 它是怎么工作的

### GLM Coding Plan（DOM 监控 + 精确刷新）

GLM 的库存状态**只存在于渲染后的页面 DOM 里**，后端接口需要鉴权 header、直接 fetch 会返回 1001。所以 GLM 采用**自动开页 + 注入脚本读 DOM** 的方案：

1. **放货窗口前**（默认 9:55，可配）自动打开 `bigmodel.cn/glm-coding`，注入内容脚本
2. 内容脚本每 10 秒扫描一次按钮 DOM；进入放货窗口后加密到每 3 秒
3. **放货那一秒**用 `setTimeout` 精确触发刷新（不受 Chrome 最小 1 分钟 alarm 限制），刷新后立刻扫描
4. **放货后 10 分钟内**持续高频扫描，捕获可能的补货
5. 检测到「售罄 → 可购买」时发送企业微信提醒，10 分钟后自动关闭监控页

**按钮状态判断**（售罄态已用真实样本验证，可购买态尚未经真实放货检验）：
| 状态 | 按钮文案 | 按钮 disabled |
|------|---------|:---:|
| 售罄 | 含 `售罄`/`补货`/`暂时`（如「暂时售罄 ｜07月30日 10:00 补货」） | 是 |
| 可购买 | `特惠订阅`/`立即订阅`/`立即购买`/`购买` | 否 |
| 繁忙 | `抢购人数过多`/`请刷新` | - |

### Kimi Code Plan（后台接口直查）

Kimi 的 `ListGoods` 接口**用浏览器 cookie 即可调用**，无需开页面：

1. 后台 Service Worker 每 10 分钟（可配）`POST` 调用 ListGoods 接口
2. 遍历返回的套餐，检查 `transitionSummary.reason` 字段：
   - `reason` 以 `REASON_SUBSCRIPTION_` 开头 = **候补中**
   - `reason` 消失或变其他值 = **已开放** → 提醒
3. 接口返回 401 / HTML 登录页 = 登录失效，发送告警并暂停判断避免误报

### 通知渠道

**企业微信群机器人**（主）：发送 markdown 消息，含套餐名、状态、直达链接。

### 登录态三道防线

放货窗口登录失效是最危险的——会错过整个放货。本插件有三道防线：

1. **预检**：放货前 30 分钟主动开页检查登录态，失效立即告警，留出时间重新登录
2. **保活**：每 30 分钟静默访问 GLM/Kimi 页面，防止 cookie 长期不用过期
3. **窗口内检测**：放货窗口期间持续检测，失效立即推送「登录过期」红色告警

## 🚀 安装与配置（详细图文教程）

### 第一步：创建企业微信群机器人（拿通知 Key）

1. 打开**企业微信**电脑端或手机端
2. 建一个群（拉几个人，或者**只有你自己**也行）
3. 进群后，点右上角 `···` → **群机器人** → **添加** → **新建机器人**
4. 给机器人取个名（比如「放货监控」），点添加
5. 复制 webhook 地址，形如：
   ```
   https://qyapi.weixin.qq.com/cgi-bin/webhook/send?key=12605dc2-xxxx-xxxx-xxxx-xxxxxxxxxxxx
   ```
6. **`key=` 后面那一串**（`12605dc2-xxxx-...`）就是你要填进插件的 Key，先复制好

> 💡 这个 Key 是公开的推送凭证，不是账号密码，泄露了别人也只能往你群里发消息。不放心可在群机器人设置里随时重置。

### 第二步：安装扩展

1. 下载本项目代码（`git clone` 或下载 ZIP 解压）
2. 打开 Chrome（或任何 Chromium 内核浏览器：Edge、Arc、Brave 等），地址栏输入 `chrome://extensions`
3. 右上角打开 **「开发者模式」** 开关
4. 点左上角 **「加载已解压的扩展程序」**，选择项目根目录（含 `manifest.json` 的那个文件夹）
5. 扩展出现在列表里，建议点 **📌 固定** 到工具栏方便随时查看

### 第三步：配置插件

1. 点工具栏的扩展图标，打开弹窗
2. **企业微信通知**卡片：把第一步复制的 Key 粘进「群机器人 Key」框，点 **「测试推送」**
3. 看企业微信群是否收到测试消息。收到 = 配置成功；没收到 = 检查 Key 是否完整
4. **GLM Coding Plan** 卡片：确认开关打开，设置：
   - 放货时间（默认 10:00）
   - 提前开页分钟（默认 5，即 9:55 自动开页）
   - 勾选要监控的套餐（Lite / Pro / Max）
5. **Kimi Code Plan** 卡片：确认开关打开，设置：
   - 检查间隔（默认 10 分钟，可调 1-60）
   - 勾选要监控的套餐（Andante / Moderato / Allegretto / Allegro）
6. 所有改动**自动保存**，右下角会闪「已保存」提示

### 第四步：确保登录态（关键！）

插件靠浏览器 cookie 工作，所以**必须先在浏览器里登录好**：

- **GLM**：打开 [bigmodel.cn](https://bigmodel.cn)，登录智谱账号
- **Kimi**：打开 [kimi.com](https://www.kimi.com)，登录月之暗面账号

登录后保持 Chrome 开着即可，**不用开着监控页面**（GLM 监控页会自动开/关）。

### 第五步：日常使用

- ✅ **保持 Chrome 开启**（Service Worker 在 Chrome 关闭时不运行）
- ✅ **保持账号登录**（插件有保活和预检，但偶尔看一眼更稳）
- ✅ 收到提醒后，点消息里的链接直达页面，**自行查看确认**
- 📋 想看监控记录？点扩展图标，「最近日志」卡片显示关键事件；后台保留完整日志供复盘

## 📋 日志与复盘

插件设计了**两层日志**：

- **前端日志**（弹窗「最近日志」）：只显示关键事件——立即检查、状态变化、登录失效、放货检测等，简洁清晰
- **后台日志**（`chrome.storage.local`，保留 500 条）：包含完整调试信息——每次扫描的原始按钮文案、Kimi 每个 reason 值、调度触发等，方便复盘为什么没抓到

放货次日想复盘？看前端日志能快速确认「几点几分扫到什么状态」；想深挖细节，后台日志有全部数据。

## ⚠️ 注意事项

- **仅提醒状态，不抢购不下单**：插件只感知并提醒套餐状态变化，不会自动购买。GLM 放货很快，收到提醒后能否买到取决于你自己操作
- **GLM 监控依赖放货窗口自动开页**：确保 9:55–10:10 这个时段 Chrome 是开着的
- **Kimi 后台 fetch 依赖浏览器 cookie**：Chrome 完全关闭时 Service Worker 不运行，需保持 Chrome 开启
- **登录态是生命线**：建议放货前一天检查登录状态，插件有预检和保活但非万无一失
- **接口可能变动**：GLM/Kimi 若改版页面或接口，判断逻辑需相应更新

## ❓ 常见问题

**Q：为什么 GLM 要开页面，Kimi 不用？**
A：GLM 的库存状态只在渲染后的 DOM 里，后端接口要鉴权 header 直接 fetch 不行；Kimi 的接口用浏览器 cookie 就能调，所以后台静默查即可。

**Q：电脑关机/Chrome 关了还能监控吗？**
A：不能。Service Worker 只在 Chrome 运行时工作。若需 7×24 监控，可考虑部署到服务器（但本插件是浏览器扩展方案，依赖浏览器 cookie）。

**Q：状态变化太快，收到提醒时已经变了怎么办？**
A：GLM 放货往往很快。插件已做到放货那一秒精确刷新，尽量第一时间发现变化，但提醒到达后页面的实际状态可能已经再次改变，请以页面为准。

**Q：企业微信机器人能推送到个人微信吗？**
A：不能直接推送到个人微信。企业微信群机器人只能推送到企业微信群。若想个人接收，可在企业微信里建个只有自己的群，或改用其他通知渠道。

**Q：登录失效了怎么办？**
A：插件会推送「登录过期」告警。打开对应平台（GLM/Kimi）重新登录即可，插件检测到恢复后会自动继续监控。
